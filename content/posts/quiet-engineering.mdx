## 왜 Quiet Engineering인가

기술 블로그의 첫 번째 목적은 멋져 보이는 화면보다 다시 읽기 좋은 기록을 만드는 것입니다.
Quiet Engineering은 과한 장식을 덜어내고 제목, 본문, 코드, 태그가 선명하게 보이도록 설계하는 방향입니다.

## 기본 구성

- 홈에서는 최근 글과 주요 주제를 빠르게 보여줍니다.
- 글 목록에서는 태그로 글을 좁혀 볼 수 있습니다.
- 글 상세에서는 본문 폭을 제한해 긴 글도 편하게 읽히도록 합니다.
- About 페이지에는 블로그의 관심사와 글쓰기 원칙을 둡니다.

## MDX로 관리하기

MDX를 쓰면 Markdown의 단순함을 유지하면서 필요한 순간 React 컴포넌트를 함께 사용할 수 있습니다.
초기에는 글을 파일로 관리하고, 글이 많아진 뒤 검색이나 RSS 같은 기능을 더해도 충분합니다.

```tsx
export function Note() {
  return <p>작게 시작하고 꾸준히 개선합니다.</p>;
}
```
